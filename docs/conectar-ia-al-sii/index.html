Cómo conectar tu asistente de IA con el SII de Chile

Con mi-sii-mcp, Claude, Codex, Gemini CLI, Cursor o VS Code leen tu IVA, tus F29, tu renta y tus boletas de honorarios desde el SII, y te responden con tus datos reales. Se instala en minutos y la clave nunca pasa por el chat.

Un asistente de IA sabe mucho de impuestos en general, pero no conoce tus números. mi-sii-mcp es un servidor MCP (Model Context Protocol, el estándar con que los asistentes usan herramientas externas) que le da acceso de solo lectura a tu información del Servicio de Impuestos Internos. Trae los datos a tu equipo, los guarda en una base local y los concilia: así puedes preguntar «¿cuadra mi IVA de septiembre con el F29?» y recibir una respuesta con cifras, no una explicación genérica.

mi-sii-mcp es un proyecto independiente de código abierto: no es una herramienta oficial del SII ni reemplaza la asesoría de un contador. No presenta declaraciones ni emite documentos.

Qué necesitas

  • Node.js 22.12 o superior, instalado en tu equipo.
  • Un asistente que ejecute servidores MCP locales: Claude Code, Claude Desktop, Codex CLI, Cursor, VS Code con Copilot, Gemini CLI, Windsurf o Cline.
  • Tu clave tributaria del SII (o tu ClaveÚnica, de forma experimental).

Paso 1: agrega mi-sii-mcp a tu asistente

No hace falta descargar el código: el asistente usa la versión publicada en npm a través de npx. Elige tu cliente:

Claude Code

Lo más completo es el plugin, que instala el servidor y una skill que le enseña al asistente a usarlo. Dentro de Claude Code escribe:

/plugin install mi-sii-mcp --marketplace Taksuma-0/mi-sii-mcp

O registra solo el servidor desde la terminal:

claude mcp add --scope user mi-sii-mcp -- npx -y mi-sii-mcp@latest mcp

Gemini CLI

La extensión trae el servidor y la skill:

gemini extensions install https://github.com/Taksuma-0/mi-sii-mcp

Codex CLI

codex mcp add mi-sii-mcp -- npx -y mi-sii-mcp@latest mcp

VS Code y Cursor

Basta un clic: instalar en VS Code o instalar en Cursor. El editor te pide confirmar y queda listo.

Claude Desktop, Windsurf, Cline y otros

Agrega esta entrada al archivo de configuración MCP de tu cliente (en Claude Desktop: Configuración → Desarrollador → Editar configuración) y reinícialo:

{
  "mcpServers": {
    "mi-sii-mcp": {
      "command": "npx",
      "args": ["-y", "mi-sii-mcp@latest", "mcp"]
    }
  }
}

Paso 2: conecta tu cuenta del SII

Esto se hace una sola vez, en tu terminal y no en el chat. Reemplaza el RUT de ejemplo por el tuyo:

npx -y mi-sii-mcp@latest login 11111111-1 --guardar-clave

El programa te pide la clave tributaria sin mostrarla y hace un solo intento. Con --guardar-clave la deja en el almacén de credenciales de tu sistema (en Windows, el Administrador de credenciales), para que la sesión se renueve sola cuando venza. Si prefieres no guardarla, omite esa opción y repite el login cuando la sesión expire.

Para entrar con ClaveÚnica usa npx -y mi-sii-mcp@latest login-navegador --rut 11111111-1: se abre Edge o Chrome en la página real del SII y mi-sii-mcp no ve lo que escribes. Esta opción es experimental y su sesión no se renueva sola.

Puedes conectar varias cuentas, por ejemplo tu RUT personal y los de tus empresas: cada una guarda su propia sesión.

Paso 3: pregunta

Reinicia tu asistente para que cargue el servidor (en Claude Code basta con /mcp) y prueba con preguntas como estas:

  • «Lista mis perfiles» (para comprobar que la cuenta quedó conectada).
  • «Trae mi IVA y mis F29 de este año y dime si algo no cuadra».
  • «¿Tengo algún F29 sin presentar o por vencer?»
  • «¿Cuánto me han retenido este año en boletas de honorarios?»
  • «Estímame la devolución de la próxima renta».

La primera vez el asistente trae los datos del SII (sincroniza); después responde desde tu base local, sin volver al portal.

Si algo no funciona

  • El asistente no ve las herramientas: reinícialo. En Claude Code, claude mcp list debe mostrar mi-sii-mcp con «Connected».
  • Error al arrancar: ejecuta npx -y mi-sii-mcp@latest mcp en una terminal para ver el mensaje; si todo está bien, dice «servidor MCP listo» y queda esperando.
  • Node antiguo: revisa con node --version que tengas la 22.12 o superior.
  • Falta la sesión: si el asistente responde que falta iniciar sesión, repite el paso 2 y vuelve a preguntar.

La guía completa tiene más detalles, como entrar a una empresa con la sesión de quien la representa.

Preguntas frecuentes

¿Funciona con ChatGPT?

mi-sii-mcp corre en tu equipo, así que funciona con los clientes que ejecutan servidores MCP locales: Claude Code, Claude Desktop, Codex CLI, Cursor, VS Code con Copilot, Gemini CLI, Windsurf o Cline. Si un cliente solo acepta servidores MCP remotos, por internet, no puede usarlo. De OpenAI, Codex CLI sí funciona.

¿Mi clave tributaria pasa por el chat?

No. Inicias sesión en tu terminal o en la página local, y ninguna herramienta del MCP recibe claves. Lo que el asistente sí ve son los datos que consulta, como cualquier cosa que le muestres.

¿Cuánto cuesta?

mi-sii-mcp es gratuito y de código abierto (licencia MIT). El costo del asistente de IA depende de su proveedor.
