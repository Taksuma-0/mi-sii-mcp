# impuestocl

Herramienta tributaria chilena de código abierto (CLI + MCP): trae tus datos desde el SII,
los guarda en tu equipo y concilia el IVA mensual.

Cobertura actual (solo lectura): RCV (compras y ventas), F29, propuesta de F29, boletas de honorarios
recibidas (con su retención frente al código 151 del F29), renta anual (F22), perfil tributario y
empresas autorizadas. No incluye otros impuestos ni áreas del portal.

Requiere Node.js >=22.12.0. Verificado con Node.js 24.

> No oficial. No está afiliada al SII. No es asesoría tributaria.

Para consultar tus datos con Claude (cruces, historial, revisión de IVA): `docs/guias/asistente-mcp.md`.
