# impuestocl

Herramienta tributaria chilena de código abierto (CLI + MCP): trae tu RCV y F29 desde el SII,
los guarda en tu equipo y concilia el IVA mensual.

Requiere Node.js >=22.12.0. Verificado con Node.js 24.

> No oficial. No está afiliada al SII. No es asesoría tributaria.

Para consultar tus datos con Claude (cruces, historial, revisión de IVA): `docs/guias/asistente-mcp.md`.
